# Getting help

- **Questions, ideas, showing what you built:** [Discussions](https://github.com/bvk7787/napier/discussions).
- **Something broken:** a [bug report](https://github.com/bvk7787/napier/issues/new?template=bug_report.yml)
  with `napier --version`, your OS, and the command and output.
- **A device you'd like covered:** a [source request](https://github.com/bvk7787/napier/issues/new?template=source_request.yml),
  or add it yourself ([docs/sources.md](docs/sources.md)) and send a pull request.
- **A publisher or maker:** the [publisher request](https://github.com/bvk7787/napier/issues/new?template=publisher_request.yml)
  form ([docs/data-policy.md](docs/data-policy.md)).
- **A security problem:** privately, as [SECURITY.md](SECURITY.md) describes.

napier is kept in spare time, so answers are best effort. Before asking, `napier status` and
[docs/mcp.md](docs/mcp.md#troubleshooting) answer the most common questions.
